Saved Tab Groups — UX Playground

All groups and actions below are demonstration data. Real browser tabs are never read or changed.

Compare approaches

  • Toolbar popup: compact, one-click group controls.
  • Sidebar: searchable, persistent group browser.
  • Individual bookmarks: one native toolbar item per mock group.
  • Bookmarks folder: native folder menu with direct links and group subfolders.

Always available

The toolbar popup is initially placed on Firefox’s bookmarks toolbar, but Firefox and the user control its actual placement. The sidebar can be opened and closed by the user.

To open the popup, click the extension’s toolbar button. Use Firefox Customize Toolbar to move or hide it.
